## QA Engineer / QA инженер

### Key Skills / Ключевые навыки

* Understanding of software development processes, testing methodologies, and QA principles  
  Знание процессов разработки ПО, методологий тестирования и принципов QA;

* Understanding of client-server architecture  
  Знание клиент-серверной архитектуры;

* Requirements and documentation analysis  
  Анализ требований и документации;

* Creation of test strategies, test plans, test cases, and checklists  
  Составление тестовых стратегий, тест-планов, тест-кейсов и чек-листов;

* Defect identification, documentation, and tracking  
  Поиск, документирование и отслеживание ошибок;

* API testing  
  Тестирование API;

* Creating and maintaining API checks and test scripts in Postman  
  Создание и поддержка API-проверок и тестовых скриптов в Postman.

**English:** Upper-Intermediate (B2)  
**Английский:** Upper-Intermediate (B2)
